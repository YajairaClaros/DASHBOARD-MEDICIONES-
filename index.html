    Ajustes

    El área del módulo se usa para la eficiencia y el rendimiento por metro cuadrado.

    MQTT

    El ESP32 publica en <tema>/datos, <tema>/termica y <tema>/estado. El tema base debe ser el mismo que TOPIC_BASE en el firmware. Si abres el tablero por https, el broker debe ser wss://. Se guarda una lectura por cada intervalo del sensor.

    Historial en la nube (Supabase)

    Con esto el tablero lee el historial completo que guarda el ESP32, igual en cualquier navegador. Usa solo la clave pública: nunca la service_role ni la contraseña de la base de datos.

    El sensor puede responder con JSON: voltage, current, irradiance, temp_panel, temp_ambient, humidity y wind. También sirven voltaje, corriente, radiacion, temperatura, temp_ambiente, humedad y viento. Si al abrir el archivo directo el navegador bloquea la petición, sirve esta carpeta con un servidor local.
